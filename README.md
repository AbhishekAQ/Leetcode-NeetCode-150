# NeetCode 150

Python solutions to the NeetCode 150.

## Layout

Folders follow the NeetCode topic order. Files are numbered 001 to 150 across the whole list, so
the number in the filename is the position in the list.

    01_arrays_and_hashing/001_contains_duplicate.py
    02_two_pointers/010_valid_palindrome.py
    07_trees/046_invert_binary_tree.py
    18_bit_manipulation/150_reverse_integer.py

Each file opens with the LeetCode number, difficulty and a link. Each one closes with the pattern
it uses, its time and space complexity, and a note on what the problem actually turns on.

## Reference

`PATTERNS.md` is the working reference: how to get from a problem's constraints to the right
approach. It covers the constraint-to-complexity budget, the tell for each of the eighteen
patterns, and the mistakes that come up repeatedly.

`TRACKER.md` holds the review schedule.

## Method

Twenty minutes per problem. If it is not solved by then, read the solution, understand why it
works, and re-solve it from an empty file three days later.

Every problem is re-solved from scratch after 3, 7 and 21 days. The notes at the bottom of each
file are what gets re-read on those days, not the code.
